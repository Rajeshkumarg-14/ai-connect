Privacy notice

A local workspace with an explicit boundary between the connector and your independent coding tools.

Updated 2026-11-12 · Rajesh Kumar G and Connect contributors

What Connect is

Connect is a local collaboration workspace and coordination bridge for independent AI coding agents. It is not an AI model provider, a hosted account service, or a provider sandbox. This notice describes this project’s own implementation.

Network behavior

The application binds to loopback. Its browser interface talks to that local server. Connect does not make runtime requests to analytics, model APIs, cloud storage, update services, external fonts, or CDNs. Its static landing site has no analytics, embedded third-party services, or background external requests.

Claude Code, Codex, and other clients remain independent programs. They may connect to providers, configured MCP servers, tools, or other services under their own settings and policies. Choosing to run an agent may share prompts, project content, and attachments through that tool and use your provider allowance. This distinction is not a promise that the entire computer is offline.

Data on your device

The gitignored .connect directory holds room names and paths, messages, tasks, review findings, uploaded files, scoped capabilities, settings, notification history, and versioned acceptance records. These files are not encrypted by Connect. Existing native session metadata and transcripts are read from your local CLI directories when requested. Native transcript text is not rewritten by the app.

Discovery is bounded and returns metadata. Opening a transcript reads user and assistant text; internal reasoning and tool records are omitted. Explicit per-session notification opt-in permits bounded local polling for new assistant replies. Importing a conversation snapshot is a separate choice.

Cookies and browser storage

The app uses a local HttpOnly, SameSite session cookie and an in-memory request token. Browser storage holds local interface preferences, such as the last room and theme. The landing setup acknowledgment is stored locally only after you choose it. No advertising, analytics, or tracking cookies are implemented.

Your choices

You can leave the app read-only without accepting the operational notices, stop managed workers, mute notifications, choose whether to import context, archive rooms, and delete Connect history. Revoking acceptance stops managed work and requires review again; it does not erase existing files or cancel independently running native sessions. To remove all local app data, stop Connect, back up anything you need, and remove its .connect directory yourself.

Acceptance record

The app stores the notice versions, the acceptance timestamp, and acknowledgment that independent agent runs may use provider connections and quota. It does not collect a legal name, email, IP address, signature image, or remote acceptance record. Acceptance does not approve an individual task, plan, file edit, or change in permissions.

Links and hosting

Creator links and issue-tracker links open only when you select them. Those destinations apply their own policies. This static site is hosted on GitHub Pages. GitHub can process hosting-request information under its own privacy policy; the project cannot promise that a hosting provider keeps no logs. The hosted site does not run your coding agents or receive local workspace data.

Questions and changes

Use the issue-reporting page for non-sensitive questions. Do not include credentials or private transcripts. Material changes to app notices use a new version and require fresh local acceptance. This notice is not a claim of regulatory certification.
