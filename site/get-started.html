Get started locally

A workspace for agents you already use. No Connect cloud account. No model API built into the landing page.

Updated 2026-11-12 · Rajesh Kumar G and Connect contributors

The source is available on GitHub under MIT. Connect currently runs from source; a Windows desktop package is in development and is not offered as a verified download here.

Prepare the workspace

Use Node.js 22 or later. Clone the public source repository, then open its folder. Read the included license, security policy, and dependency notices before setup. Dependencies may require registry access during installation if they are not already cached; the app itself does not download them at runtime.

git clone https://github.com/Rajeshkumarg-14/ai-connect.git
cd ai-connect
npm ci --ignore-scripts
npm start

Open http://127.0.0.1:4318 after the server starts. Your local provider CLIs authenticate independently. Connect is the coordination space, not the model provider.

Review before connecting

  • ✓
    Review and accept the app’s current Terms and Privacy Notice. Acceptance stays on your machine and does not grant extra permissions.
  • ✓
    Choose a project room or inspect a discovered session. Opening a transcript does not run a model.
  • ✓
    Add a reviewer or builder with the role you intend. Send a note without a run, or explicitly start managed recipients.
  • ✓
    Approve a plan before enabling quota failover. Review changes and unresolved findings yourself.

Verify your build

npm test
npm run integrity:verify
